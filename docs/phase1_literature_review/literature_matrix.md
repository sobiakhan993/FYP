# Literature Review Matrix: State-of-the-Art Analysis

This matrix consolidates and categorizes key literature on **Ransomware Detection**, **Adversarial Machine Learning / Poisoning Defenses**, and **Cloud Monitoring Telemetry**, highlighting the research gap addressed by our unified system.

| Ref | Authors & Title | Year | Theme | Problem Addressed | Dataset / Testbed | Method / Algorithm | Key Results | Limitations / Research Gap |
|---|---|---|---|---|---|---|---|---|
| **[1]** | Scaife et al., *"CryptoLock (and Drop It): Stopping Ransomware at File System"* | 2016 | Ransomware Detection | Early-stage ransomware encryption detection on local filesystems | 492 ransomware binaries, 14 families | Behavioral metrics: file entropy, file type change, process I/O burst rate | 100% detection rate on tested dataset; lost only ~10 files before halt | Evaluated strictly on local endpoint filesystems; does not address cloud object storage or shared cloud drives. |
| **[2]** | Continella et al., *"ShieldFS: A Self-healing Filesystem"* | 2016 | Ransomware Detection | Low-level driver-based ransomware detection and automated rollback | Hundreds of benign apps & ransomware samples | File activity profiling, write-frequency, entropy, VFS driver interception | >97% detection accuracy; near-zero data loss via copy-on-write buffer | High kernel driver overhead; unsuitable for multi-tenant serverless or virtualized cloud instances. |
| **[3]** | Sgandurra et al., *"Automated Dynamic Analysis of Ransomware (EldeRan)"* | 2017 | Ransomware Detection | Automated dynamic feature analysis of ransomware execution | 582 ransomware & 942 benign binaries | Dynamic registry, API calls, file ops, directory enumerations, Regularized Logistic Regression | 96.34% detection rate with 1.6% false positive rate | Offline batch sandbox analysis; cannot handle streaming live cloud telemetry in real time. |
| **[4]** | Bae et al., *"Ransomware Detection Using ML Based on API & File Events"* | 2020 | Ransomware Detection | Distinguishing benign disk activity from fast cryptors | Public malware repository & Windows API telemetry | Random Forest, XGBoost, API n-grams, file frequency ratios | 98.1% F1-score on tabular feature vectors | Relies exclusively on static/dynamic API trace logs; misses cloud-specific storage anomalies (e.g. S3/Blob bursts). |
| **[5]** | Cabaj & Mazurczyk, *"Using Software-Defined Networking for Ransomware Mitigation"* | 2016 | Ransomware Detection | Command-and-Control (C2) communication & key exchange interception | CryptoWall network traffic traces | SDN OpenFlow controller inspecting HTTP/DNS C2 traffic | Intercepts C2 communication before encryption key negotiation | Useless against modern offline-key or pre-bundled encryption key ransomware variants. |
| **[6]** | Davies et al., *"CloudRanger: Rapid Ransomware Identification in Cloud"* | 2021 | Ransomware Detection | Virtual machine volume encryption in Infrastructure-as-a-Service (IaaS) | Cloud hypervisor disk I/O traces, RanSim | 1D-CNN and LSTM on sequential disk block read/write patterns | 95.8% accuracy within 45 seconds of attack initiation | Computationally heavy deep learning; black-box decision making without explainability (SHAP). |
| **[7]** | Alhawi et al., *"Leveraging ML for Windows Ransomware Network Traffic"* | 2018 | Ransomware Detection | Network-level anomaly detection of encryption propagation | UNSW & internal malware lab traffic | SVM, Naive Bayes, Decision Trees | 97.1% accuracy on packet header timing and byte distributions | High false positive rate on legitimate cloud bulk synchronization and compression operations. |
| **[8]** | Al-Rimawi et al., *"Comparative Study of ML Classifiers for Ransomware"* | 2021 | Ransomware Detection | Benchmarking diverse ML models on dynamic features | Dynamic file modification & entropy traces | Random Forest, SVM, KNN, AdaBoost, MLP | Random Forest achieved 98.4% accuracy; highest robustness to noise | Lacks anomaly detection for novel zero-day malware patterns never present in training data. |
| **[9]** | Zahoora et al., *"Deep learning dynamic ransomware detection via API & entropy"* | 2022 | Ransomware Detection | Multi-stage ransomware execution with delayed encryption | Hybrid sandbox telemetry | Autoencoder + Bi-LSTM on sliding time windows | 98.6% recall on evasive samples | Requires long sequence observation windows; inference latency exceeds real-time alerting targets. |
| **[10]** | Kok et al., *"RanCross: Cross-Platform Feature Extraction"* | 2020 | Ransomware Detection | Cross-platform malware portability across Windows and Linux | Cross-platform corpus of 1,200 binaries | Gradient Boosting on entropy distributions and file header alterations | 96.7% detection rate across platforms | Evaluated offline; no pipeline connecting cloud API events (AWS CloudTrail, Azure Audit). |
| **[11]** | Kharaz et al., *"UNVEIL: Large-Scale Automated Approach to Ransomware"* | 2016 | Ransomware Detection | Detecting silent lockers and desktop lockers | 148,000 malware samples | Synthetic user environment, I/O access monitor, screen change detection | High detection fidelity across widespread malware families | Heavyweight desktop GUI requirements; completely unsuited for cloud headless virtual instances. |
| **[12]** | Nguyen et al., *"Cloud-Guard: Real-Time Behavioral Anomaly in Cloud VMs"* | 2022 | Ransomware Detection | Detecting hypervisor disk spikes and anomalous process spawning | Cloud testbed running QEMU/KVM | Isolation Forest & One-Class SVM on VM metrics | 94.2% detection with 4.8% false positive rate | Evaluated anomaly detection only; lacks supervised pattern discrimination for recognized attack families. |
| **[13]** | Biggio et al., *"Poisoning Attacks against Support Vector Machines"* | 2012 | Poisoning Defenses | Gradient-based training data poisoning to degrade classifier margins | MNIST, Spambase | Gradient ascent optimization maximizing validation error | Increased SVM error rate from 3% to over 24% with only 8% poisoned points | Proved vulnerability of ML classifiers; no automated defense or quarantine pipeline provided. |
| **[14]** | Jagielski et al., *"Manipulating Machine Learning: Poisoning Attacks & Countermeasures"* | 2018 | Poisoning Defenses | Optimal poisoning attacks on regression & classification; defense limits | Ridge, LASSO, linear classifiers | Optimization framework for adversarial insertion; TRIM defense algorithm | TRIM effectively mitigated up to 10% poisoning on synthetic setups | TRIM assumes linear models; computationally infeasible on non-linear tree ensembles (RF, XGBoost). |
| **[15]** | Shafahi et al., *"Poison Frogs! Targeted Clean-Label Poisoning on NNs"* | 2018 | Poisoning Defenses | Injecting poisoned inputs without modifying dataset class labels | Feature-collision optimization in latent feature space | Interpolation in representation space to create visually normal samples | >60% target misclassification without mislabeled training samples | Highlights that simple label validation is insufficient; feature distribution outlier detection is vital. |
| **[16]** | Chen et al., *"Detecting Backdoors on Deep Neural Networks by Activation Clustering"* | 2019 | Poisoning Defenses | Detecting poisoned clusters inserted into neural network training sets | Benchmark image and tabular datasets | Activation clustering (k-Means, ICA) in hidden representation layers | Successfully detected backdoor triggers across 92% of test cases | Restricted to deep neural networks; does not address tabular cloud security feature spaces. |
| **[17]** | Paudice et al., *"Detection of Adversarial Training Examples using Label-Sanitization & k-NN"* | 2018 | Poisoning Defenses | Detecting label-flipping and adversarial outliers in training corpora | MNIST, Breast Cancer, Spambase | k-Nearest Neighbor (k-NN) voting consistency and distance thresholds | Filtered out >90% of label-flipped data with <3% benign false quarantine | Evaluated on static offline datasets; not integrated into automated cloud model retraining pipelines. |
| **[18]** | Koh & Liang, *"Understanding Black-box Predictions via Influence Functions"* | 2017 | Poisoning Defenses | Identifying the most influential training samples that alter model decisions | Tabular benchmarks & image classifiers | Empirical Hessian approximation and influence calculation | Successfully pinpointed poisoned samples causing test misclassifications | Very slow quadratic computational complexity; impossible for high-velocity real-time retraining checks. |
| **[19]** | Severi et al., *"Explanation-Guided Backdoor Poisoning Attacks against Malware Classifiers"* | 2021 | Poisoning Defenses | Exploiting SHAP explanations to craft robust backdoor triggers in malware classifiers | Ember malware benchmark (Windows PE features) | Feature-selection via SHAP values, watermarking clean malware samples | 98% backdoor attack success with less than 1% clean accuracy impact | Demonstrates severe danger of poisoning in cyber defense models; proves models must validate training data. |
| **[20]** | Steinhardt et al., *"Certified Defenses for Data Poisoning Attacks"* | 2017 | Poisoning Defenses | Theoretical upper bounds on test loss under worst-case data poisoning | General tabular convex learning problems | Outlier removal via spectral clustering and convex relaxation | Upper bounded empirical risk under bounded fractions of poisoning | Assumptions require strictly convex losses and Gaussian assumptions rarely met in cyber telemetry. |
| **[21]** | Chen et al., *"Targeted Backdoor Attacks on Deep Learning Systems"* | 2017 | Poisoning Defenses | Backdoor triggers activated only upon specific trigger key presence | Benchmark datasets | Injection of targeted patterns into training subsets | 99% trigger activation rate with negligible effect on clean validation accuracy | Emphasizes necessity of both unsupervised outlier screening and validation set gating. |
| **[22]** | Nicolae et al., *"Adversarial Robustness Toolbox (ART)"* | 2020 | Poisoning Defenses | Standardizing adversarial ML attack & defense implementations | Multi-domain synthetic and standard datasets | Library implementing label-flipping, clean-label, LOF, clustering defenses | Standardized framework for adversarial testing | General software library; not an end-to-end security operational system or monitoring dashboard. |
| **[23]** | Liu et al., *"Trojaning Attack on Neural Networks"* | 2018 | Poisoning Defenses | Modifying internal weights and retraining on synthetic trojan data | Face recognition, speech, self-driving | Reverse engineering internal neuron activations and generating triggers | Trigger success rate >98% | Requires access to model training loop; demonstrates necessity of model validation checkpoints before deployment. |
| **[24]** | Cretu et al., *"Casting Out Demons: Data Sanitization for Anomaly Sensors"* | 2008 | Poisoning Defenses | Preventing attackers from training anomaly sensors to accept malicious behavior | Network packet payloads | Micro-model clustering sanitization; training data filtering | Prevented sensor blinding by up to 95% on simulated network worms | Early work based on payload heuristics; lacks modern ML classifiers and cloud log telemetry. |
| **[25]** | Chiba et al., *"Real-time ML Architecture for Cloud Security Audit Log Analysis"* | 2022 | Cloud Telemetry & Logging | Automated detection of malicious privilege escalation and account hijacking | AWS CloudTrail audit logs, synthetic user sessions | Spark Streaming, Random Forest, sliding time-window feature aggregation | Detected 96% of unauthorized API invocations within 3 seconds | Focuses exclusively on identity/IAM anomalies; ignores disk entropy and ransomware file destruction. |
| **[26]** | Pour & Injadat, *"Streaming Intrusion Detection in Cloud Using Incremental ML"* | 2021 | Cloud Telemetry & Logging | Adapting to concept drift in cloud network intrusion detection | CIC-IDS2017, NSL-KDD | Hoeffding Trees, Adaptive Random Forests, streaming feature buffers | 97.4% accuracy with sub-second stream adaptation | Vulnerable to poisoning drift: malicious streams silently contaminate the incremental decision boundaries. |
| **[27]** | Mirsky et al., *"Kitsune: An Ensemble of Autoencoders for Online NIDS"* | 2018 | Cloud Telemetry & Logging | Unsupervised lightweight anomaly detection on streaming network packets | Mirai, video injection, ARP spoofing packet streams | Damped incremental statistics, ensemble of lightweight neural autoencoders | Sub-millisecond packet processing; high detection rate | Unsupervised only; produces false alarms on benign burst transfers; no supervised classifier to distinguish ransomware. |
| **[28]** | Sommer & Paxson, *"Outside the Closed World: Using ML for Network Intrusion Detection"* | 2010 | Cloud Telemetry & Logging | The fundamental gap between academic ML models and operational reality in security | Theoretical security operations critique | Qualitative analysis of false positives, concept drift, and semantic gaps | Foundational guidelines for practical cybersecurity ML | Proves that raw anomaly detection yields excessive false alarms without supervised combination and explainability. |
